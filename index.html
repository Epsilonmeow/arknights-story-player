下载酒馆助手导入脚本

  1. 准备 SillyTavern 和酒馆助手。本轮实测版本为 1.18.0 / 4.12.0，此前已核对助手 4.11.0 的所需接口。
  2. 在酒馆助手脚本库导入下载的 JSON，然后开启。已有旧播放器时先关闭旧脚本。
  3. 在播放器设置中填写自己的 API URL、Key 和标注模型。无密钥服务可留空。
  4. 读取已有 AI 回复，再手动请求演出标注。重新标注会发起一次新请求，费用由你的服务商计算。
